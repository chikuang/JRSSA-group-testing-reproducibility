# Original reproduction scripts

These source files are retained unchanged from gtDesign. The table/figure numbers
in their filenames refer to an earlier manuscript. See the current
[Table and Figure index](../../PAPER_REPRODUCTION.md) and
[machine-readable mapping](../../paper_items.csv) before choosing a script.
Run a source file through `Rscript scripts/run_original.R <path>` from the
repository root so it uses the installed gtDesign package.
